## 🌸 About This Repository

This repository documents my practical work in **Integrative Programming**, where I explored how different technologies, databases, APIs and security mechanisms can be brought together to build interconnected applications.

The coursework focused heavily on backend development using **JavaScript and Node.js**, building RESTful APIs with **Express.js**, connecting applications to an **Oracle Database**, and progressively introducing authentication, authorization and API security concepts.

It was one of the courses that helped me see how different pieces of a technology stack communicate and work together. 🔗✨

## 🌐 REST API Development

A major part of the coursework involved designing and implementing API endpoints using **Node.js and Express.js**.

The exercises progressively introduced operations for retrieving, creating and updating resources through HTTP endpoints.

Examples included endpoints for:

- Retrieving records from an Oracle database
- Creating new database records
- Managing users
- Managing publications
- Assigning publications to users
- Updating publication statuses
- Updating user information

This gave me practical experience connecting an application layer to a relational database through an API.
